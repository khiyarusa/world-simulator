# Stage 4 visual QA captures

Every image here was produced by the real production build (`dist/`) at **390 × 844 CSS px, DPR 2**,
in Chromium/WebGL (SwiftShader in CI). They are not mockups. They are regenerated by:

```bash
npm run build
npm run test:visual        # writes docs/qa/stage4/*.jpg
```

The CI `verify` job runs the same command and uploads the folder as `visual-qa-<sha>`.
